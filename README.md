# 写真スライドショー

Macでは「写真」のアルバムを、Windowsでは選択したフォルダの画像を全画面で再生します。設定、お気に入り、取得元ごとの再開位置は端末に保存されます。

## 起動

| 配布ファイル | 対象 | 起動方法 |
| --- | --- | --- |
| `PhotoSlideshow-1.4.1-macOS-arm64.zip` | macOS 14以降、Apple Silicon | ZIPを展開し、`写真スライドショー.app` を開きます。初回は写真へのアクセスを許可し、アルバムを選びます。 |
| `PhotoSlideshow-1.4.1-Windows-x64.zip` | Windows x64。Windows 11を想定 | ZIPをすべて展開し、展開先の `PhotoSlideshow.exe` を開いて画像フォルダを選びます。.NETランタイムは同梱されています。 |

Mac版はアドホック署名で公証を行っていません。Windows版はAuthenticode署名を行っていません。OSのセキュリティ設定により初回起動が制限される場合があります。

Windows版は選択したフォルダ直下のJPEG、PNG、BMP、GIF、TIFFを、ファイルの更新日時が古い順に表示します。

## 再生

- ポインタを操作バーの付近に移動するとバーが出ます。離れてから設定した秒数が経つと隠れます。
- ホイールまたは左右キーで前後へ移動します。左ボタンを押しながら下へ回すと拡大、上へ回すと縮小します。再生中は倍率が変わった時点から表示時間を数え直します。
- スペースで一時停止と再開、Escまたはバーの戻るボタンで終了します。
- 写真や黒い余白をダブルクリックすると、お気に入りに登録します。登録済みの写真では、ピンクの♥が短く光ります。操作バーのハートをクリックすると登録・解除を切り替えられます。
- 写真一覧ではサムネイルを選んで移動できます。「お気に入り」で絞り込み、サムネイル上のハートから対象を解除できます。

## 配置を編集

1. 設定の「配置を編集」を開きます。時計をオフにしている場合も、時計・ハート・操作バーの見本を操作できます。
2. 枠をドラッグして移動し、角をドラッグして縦横比を保ったままサイズを変更します。枠が重なる場合は画面下部の要素選択を使えます。
3. 選んだ要素の「位置を戻す」「サイズを戻す」、または「すべて初期値に戻す」で配置を戻せます。「設定に戻る」で配置を確認し、設定の「閉じる」で保存します。

設定からハートを左上・右上・カスタムに切り替えられます。時計とハートが重なる場合は時計が上になります。バーと写真を重ねたくない場合は「操作バー分の余白を確保」を選んでください。

## ビルド

Mac版は Swift 6 を含む Xcode Command Line Tools を使います。Windows版は .NET 10 SDK でビルドできます。Windows x64へのクロスビルドはMacでも実行できます。

```sh
zsh macOS/build.sh
dotnet publish Windows/PhotoSlideshow.csproj -c Release -r win-x64 --self-contained true -o build/win-x64
```

## 検証範囲

Macの実機ではApple Silicon上のmacOSで、合成写真でも配置編集と保存・復元を確認しました。Windows版はGitHub ActionsのWindows Server 2022上でWinFormsの自動試験を行いました。Windows 11の実機、物理マウスの機種差、実ディスプレイでのDPIや複数画面の切り替え、長時間放置での自動消灯は今回の検証範囲外です。
